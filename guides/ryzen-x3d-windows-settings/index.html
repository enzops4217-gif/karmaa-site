Ryzen X3D: the best Windows settings for gaming

Updated November 22, 2026 · 6 min read

AMD’s X3D processors owe their gaming speed to an extra layer of cache. To get it, the game must run on the cores that have that cache, and your RAM and BIOS must be set right. Here is how to set up Windows and the BIOS for a 5800X3D, 7800X3D, 9800X3D or a dual-CCD 7900X3D, 7950X3D, 9900X3D or 9950X3D.

First: which X3D do you have?

There are two families, and they do not need the same setup:

TypeModelsWhat it means
Single CCD5600X3D, 5700X3D, 5800X3D, 7600X3D, 7800X3D, 9800X3DAll cores have the extra cache. No core selection problem.
Dual CCD7900X3D, 7950X3D, 9900X3D, 9950X3DOnly one of the two core groups (CCD) has the extra cache. Games must be sent to that group.

On dual-CCD chips, if a game lands on the CCD without V-Cache, it can lose a big part of the X3D advantage. Most of this guide is about avoiding that. Single-CCD owners can skip to the RAM and BIOS sections.

1. Update the BIOS

Go to your motherboard’s support page (ASUS, MSI, Gigabyte, ASRock…), find your exact model and install the latest stable BIOS, following the maker’s method (usually a USB stick and the BIOS flash tool). Recent BIOS versions bring AGESA updates that improve memory compatibility, fix bugs and, on AM5, apply AMD’s safe voltage limits for X3D chips. Do not flash during a storm or on an unstable power supply.

After updating, the BIOS resets to defaults: you will need to turn EXPO back on.

2. Install the AMD chipset driver

  1. Go to AMD’s drivers page, choose Chipsets, then your socket (AM4 or AM5) and your chipset.
  2. Download and install the latest version. Keep all components checked.
  3. Restart.

On dual-CCD X3D processors, this package installs the AMD 3D V-Cache Performance Optimizer driver. You can check it in Device Manager → System devices, and in Services (look for “AMD 3D V-Cache Performance Optimizer Service”). Without it, Windows does not know which CCD to prefer for games.

Changed your CPU without reinstalling Windows? AMD recommends reinstalling the chipset driver after a CPU swap, and ideally a clean Windows install when moving to a dual-CCD X3D. At the very least, uninstall the old chipset driver, restart and install the new one.

3. Keep Game Mode on and the Xbox Game Bar up to date

On dual-CCD models, AMD’s driver uses the Xbox Game Bar to know when a game is running. So, contrary to many “debloat” guides:

  • Keep Settings → Gaming → Game Mode on.
  • Do not uninstall the Xbox Game Bar. Update it in the Microsoft Store (Library → Get updates).
  • If a game is not detected as a game, open the Game Bar (Win + G) while it runs, go to Settings and check Remember this is a game.

You can still turn off background recording (Settings → Gaming → Captures) without breaking detection.

4. Power plan: Balanced on dual-CCD models

On 7900X3D, 7950X3D, 9900X3D and 9950X3D, the driver moves games to the V-Cache CCD by parking the other CCD’s cores while you play. Core parking depends on the power plan, and AMD’s guidance is to keep Windows on Balanced. Plans like High performance or Ultimate Performance turn core parking off, and the game can spread over both CCDs.

On single-CCD chips (7800X3D, 9800X3D, 5800X3D…), you can use Balanced or a performance plan; the difference is usually small. Measure in your games.

5. Turn on EXPO or XMP and pick the right memory speed

X3D chips are less sensitive to RAM speed than other CPUs thanks to their large cache, but leaving your RAM at default speed still costs performance.

  • AM5 (7000 and 9000 series, DDR5): enable EXPO in the BIOS. The usual sweet spot is DDR5-6000 CL30, with the memory controller in 1:1 mode (UCLK = MEMCLK). Most BIOS set this automatically with a 6000 kit.
  • AM4 (5000 series, DDR4): enable XMP/DOCP. The common sweet spot is DDR4-3600 CL16 with Infinity Fabric at 1800 MHz (1:1).
  • Check in Windows: Task Manager → Performance → Memory shows the speed. CPU-Z (Memory tab) shows the DRAM frequency, which is half the rated speed (3000 MHz = DDR5-6000).

After enabling EXPO, test stability: play for a few hours or run a memory test. If the PC crashes or does not boot, go back to the default profile or a slightly lower speed.

6. Useful BIOS options

  • CPPC and CPPC Preferred Cores: leave on Auto or Enabled.
  • CPPC Dynamic Preferred Cores (dual-CCD AM5 boards): the default (Auto / Driver) lets AMD’s driver decide. Setting it to Cache always prefers the V-Cache CCD, which can help if detection fails, but can slow down non-gaming tasks that prefer high clocks. Change it only if you have a reason.
  • PBO and Curve Optimizer: on 7000X3D and 9000X3D chips, PBO with a negative Curve Optimizer (undervolt) can lower temperatures and raise boost clocks. It is optional, and every chip is different: start small (for example −10), test stability for a long time, and go back to default at the first crash. The 9800X3D also allows real overclocking; the 5800X3D does not.
  • SVM / virtualization: only turn it off if you never use virtual machines, WSL or apps that need it, and if your anti-cheat does not require it. It is not a performance setting on its own.

7. Check that the game runs on the right cores

On dual-CCD models:

  1. Open Task Manager → Performance → CPU, right-click the graph and choose Change graph to → Logical processors.
  2. Launch your game and play for a minute.
  3. On a 7950X3D or 9950X3D, the V-Cache CCD is usually the first one (cores 0–7, logical processors 0–15). These should be busy, while the second half should show as parked or nearly idle.

If both halves are busy, check in order: chipset driver installed, Balanced plan, Game Bar up to date, game marked as a game in the Game Bar. Tools like HWiNFO also show per-core usage and clocks.

Some players force the game onto the V-Cache cores with tools like Process Lasso. It can work, but it can also conflict with AMD’s driver. Try the official setup first.

8. The usual Windows settings still apply

The rest of your Windows setup is the same as for any gaming PC: correct refresh rate, background recording off, startup apps trimmed, up-to-date graphics driver. See our Windows 11 settings guide and our input lag guide.

Summary

  • Latest BIOS and AMD chipset driver, reinstalled after a CPU swap.
  • EXPO on (DDR5-6000 CL30, 1:1 is the usual target on AM5).
  • Dual-CCD: Game Mode on, Game Bar up to date, Balanced power plan, check core usage in Task Manager.
  • Single-CCD: nothing special on the core side, just the usual Windows settings.
  • Undervolting is optional and needs proper stability testing.
