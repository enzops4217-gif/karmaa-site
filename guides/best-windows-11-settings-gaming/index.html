The best Windows 11 settings for gaming

Free guideUpdated November 22, 20266 min read

Windows 11 is a good gaming OS out of the box, but a few defaults hold it back: wrong refresh rate, balanced power, background recording, startup apps. Here are the settings worth changing, where to find them, and the ones you should leave alone.

Before you start

Create a restore point: search “Create a restore point” in the Start menu, select your system drive, click Configure to turn protection on if needed, then Create. Then pick a test scene in one of your games and note your average FPS and 1% lows. Change settings in small groups and measure again. A setting that helps one PC can do nothing on another.

1. Update Windows and your drivers

  • Windows Update: install pending updates, including optional driver updates only if you know what they are.
  • Chipset driver: download it from AMD or Intel (or your motherboard’s support page). On AMD Ryzen it also installs the power management pieces the CPU needs.
  • Graphics driver: get it from NVIDIA, AMD or Intel directly. The driver offered by Windows Update is often older.
  • BIOS: check for updates on your motherboard’s support page, and turn on XMP (Intel) or EXPO (AMD) so your RAM runs at its rated speed. Without it, many kits run far slower than what you paid for.

2. Turn on Game Mode

Go to Settings → Gaming → Game Mode and turn it on. It is on by default on most PCs. Game Mode gives priority to the game, stops Windows Update from installing drivers or showing restart notifications while you play. Old advice to turn it off dates back to early Windows 10 bugs that are long fixed. On AMD Ryzen 7900X3D, 7950X3D, 9900X3D and 9950X3D, Game Mode is even required for the CPU to pick the right cores (see our Ryzen X3D guide).

3. Set up graphics correctly

Refresh rate

Settings → System → Display → Advanced display → Choose a refresh rate: pick the highest value. Dynamic refresh rate is only useful on laptops; on a desktop, keep your fixed maximum.

Optimizations for windowed games and GPU scheduling

Settings → System → Display → Graphics → Advanced graphics settings:

  • Optimizations for windowed games: turn it on. It lets older DirectX 10/11 games running in borderless mode use the lower-latency flip model.
  • Hardware-accelerated GPU scheduling (HAGS): required for NVIDIA Frame Generation (DLSS 3 and later). Outside of that, its effect varies; measure with it on and off (restart each time).
  • Variable refresh rate: turn it on if you have a G-Sync or FreeSync monitor.

GPU preference per game (laptops and PCs with two GPUs)

On the same Graphics page, add your game’s .exe and set it to High performance. On a laptop, this makes sure the game runs on the dedicated GPU, not the integrated one.

4. Use a performance power mode

Go to Settings → System → Power & battery → Power mode and choose Best performance. On a desktop, you can also open the classic Control Panel → Power Options and select High performance. The hidden Ultimate Performance plan exists, but on most gaming PCs it brings no measurable gain over High performance and keeps the CPU from resting.

Exception: on dual-CCD Ryzen X3D chips, AMD recommends the Balanced plan, because the core parking that sends the game to the right cores relies on it.

5. Turn off background captures

Go to Settings → Gaming → Captures and turn off Record what happened. Background recording keeps encoding video while you play. If you use the NVIDIA App or AMD Software to record clips, choose one tool and turn off instant replay in the others.

You do not need to uninstall the Xbox Game Bar: some features (Game Mode detection, the X3D driver on AMD) depend on it.

6. Trim startup apps and notifications

  • Task Manager → Startup apps: disable launchers, updaters, RGB and cloud tools you do not need at every boot. Keep your audio, graphics and antivirus entries.
  • Settings → Apps → Installed apps: uninstall trial software and toolbars that came with the PC.
  • Settings → System → Notifications: turn on Do not disturb automatically “When playing a game”.
  • Settings → Windows Update → Advanced options → Active hours: set them to the hours you play, so Windows never restarts in the middle of a session.

7. Memory integrity and VBS: know the trade-off

Windows 11 enables Virtualization-Based Security (VBS) and Memory integrity (HVCI) on many new PCs. Microsoft itself has said they can lower performance in some games, and gives the option to turn them off for gaming. But they also protect you against kernel-level malware.

  • To check: open Windows Security → Device security → Core isolation details.
  • If you turn Memory integrity off, restart and measure. If the gain is not clear on your PC, turn it back on.
  • Some anti-cheats (for example FACEIT or Vanguard) may ask for these features to be on. Follow what your games require.

This is your choice to make with the facts in hand. We do not recommend turning security off blindly.

8. Mouse and keyboard

  • Control Panel → Mouse → Pointer Options: uncheck Enhance pointer precision.
  • Settings → Accessibility → Keyboard: make sure Sticky Keys and Filter Keys shortcuts are off, so pressing Shift five times never opens a pop-up mid-game.
  • Set your mouse to 1000 Hz or more and plug it into a rear USB port. More in our guides on polling rate and USB ports.

9. Storage and free space

Install your games on an SSD (NVMe if possible). Keep at least 15–20% free space on it. Turn on Storage Sense (Settings → System → Storage) to clean temporary files automatically. Do not disable TRIM or the scheduled optimization of drives: on SSDs, Windows runs TRIM, not a defragmentation.

What to leave alone

  • Do not disable Windows Defender for performance. If a scan runs while you play, schedule it instead.
  • Do not disable services in bulk with scripts you have not read. You can break updates, audio, Bluetooth or your anti-cheat.
  • Do not turn off the page file, even with lots of RAM: some games crash without it.
  • Do not use “RAM cleaner” apps: Windows manages memory better on its own.
